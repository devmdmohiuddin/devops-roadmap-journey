# My SDLC → DevOps Tool Map

| SDLC Phase | Tool(s) I'll  User | What It Automates |
|------------| -------------------|-------------------|
| Plan | Trello/Jira/Linear, Azure Boards | Tracking project tasks, user stories, and linking tickets to code changes |
| Code | Git, Github/GitLab/Bitbucket, VS Code | Version control, collaboration, branching, and pull request reviews |
| Build | Maven/Gradle (Java), npm/webpack (Javascript), pip (Python) | Packaging the application and its dependencies into a consistent environment |
| Test | Jest, JUnit, PyTest, Selenium, Cypress | Automatically running unit tests and validation on every push and pull request |
| Release | Semantic versioning, GitHub Releases, Nexus/Artifactory, Docker Hub | Storing, versioning, and distributing Docker images | 
| Deploy | Jenkins, Github Actions, ArgoCD, Kubernetes, Ansible, Terraform | Automatically deploying applications to servers or clusters |
| Operate | Kubernetes, AWS/Cloud infrastructure, Ansible | Provisioning and managing infrastructure as code |
| Monitor | Prometheus, Grafana, ELK Stack, Datadog | Monitoring application performance, collecting metrics, and visualization system health |
